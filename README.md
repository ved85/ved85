# 🚀 Featured Project — VDoc

## 🩺 VDoc — Multimodal AI Personal Doctor Assistant

**VDoc** is my final-year project and one of my main AI engineering projects.

It is a **multimodal AI personal health assistant** designed around evidence-based responses, document reasoning, visual reasoning and retrieval-augmented generation.

### Key Technologies

- Python
- FastAPI
- LlamaIndex
- RAG
- ChromaDB
- SQLite
- Ollama
- Cloud LLM inference
- Vision-Language Models (VLMs)
- Ultralytics YOLO
- PIL
- Human feedback
- REST APIs

### Architecture

VDoc uses a modular architecture with:

```text
User
  │
  ▼
FastAPI Orchestration Layer
  │
  ├── Model Manager
  │      ├── Local Ollama Models
  │      └── Cloud LLM Models
  │
  ├── Conversation Memory
  │
  ├── RAG Pipeline
  │      ├── Document Ingestion
  │      ├── Cleaning & Chunking
  │      ├── Embeddings
  │      ├── ChromaDB
  │      ├── Retrieval
  │      └── Prompt Construction
  │
  └── Multimodal Processing
         ├── Text
         ├── Documents
         └── Images
````

The system supports **local and cloud-based inference**, allowing models to be switched without losing conversational context.

I also designed the system to support **online/offline operation**, multiple users and parallel requests.

### 🏆 Recognition

VDoc was awarded **£5,000 through the Cal Henderson Innovation Seed Fund** in recognition of its innovation potential.
